# ha-shenzhen-gas

深圳燃气 Home Assistant 自定义集成，用于读取深圳燃气微信小程序接口中的燃气表、用气和账单数据。

## 功能

- 累计读数
- 今日用气量
- 昨日用气量
- 用气日期
- 余额
- 上期账单金额
- 上期用气量
- 阶梯气费
- 上期账单周期
- 下一账单日
- 最新读数
- 最近更新
- 阀门状态
- 电池电量
- 在线状态

集成类型为 `cloud_polling`，默认每 30 分钟刷新一次数据。

## 安装

### HACS

1. 打开 HACS。
2. 进入“集成”。
3. 点击右上角菜单，选择“自定义存储库”。
4. 添加仓库：

   ```text
   https://github.com/lcx565656/ha-shenzhen-gas
   ```

5. 类别选择“集成”。
6. 搜索并安装“深圳燃气”。
7. 重启 Home Assistant。

### 手动安装

1. 下载本仓库。
2. 将 `custom_components/shenzhen_gas` 复制到 Home Assistant 的 `custom_components` 目录。
3. 重启 Home Assistant。

目录结构应类似：

```text
config/
  custom_components/
    shenzhen_gas/
      manifest.json
      sensor.py
      ...
```

## 配置

重启后，在 Home Assistant 中进入：

```text
设置 -> 设备与服务 -> 添加集成 -> 深圳燃气
```

只需要填写：

| 字段 | 说明 |
| --- | --- |
| CodeId | 深圳燃气微信小程序请求头中的 `CodeId`（即 openid） |

客户号、表号、`accountChannelId` 全部由接口自动识别，不需要手工填写。集成会根据 `CodeId` 读取微信小程序中已绑定的深圳燃气账户；若当前微信账号绑定了多个账户，配置流程会让你选择要添加的账户。

集成内部会调用 `/api/handle/fraccountchannel/findAccountByOpenID`，用 `CodeId` 换出该账号的 `accountChannelId`，再带上它请求业务接口。这个渠道号不落盘，每次都是按当前 `CodeId` 现取现用。旧版本把一个固定的 `accountChannelId` 写死了，导致其他用户全部返回 `40510 无权限访问！`；当前版本已改为自动解析，并会清理旧配置项里的残留字段。

`CodeId` 获取方式见：[获取 CodeId 教程](docs/get-codeid.md)。

### CodeId 失效了怎么办

进入「设置 → 设备与服务 → 深圳燃气 → 配置」，直接改 `CodeId` 再保存即可，不需要删掉集成重加。保存时会立即校验，校验通过后自动重载。

### 敏感信息保存在哪

`CodeId`、客户号、表号**只保存在你自己 Home Assistant 的 `config/.storage/core.config_entries` 里**，由你在网页表单中填写；`accountChannelId` 由 `CodeId` 每次现取，不落盘。仓库里不含任何个人数据。

## 设置项

除了 `CodeId`，唯一需要（也可以不）调整的是**刷新间隔**：

```text
设置 -> 设备与服务 -> 深圳燃气 -> 配置 -> 刷新间隔（分钟）
```

默认 30 分钟，可填 5 ~ 1440。

其余参数（API 域名、渠道类型、小程序版本、User-Agent、token 凭据、请求超时）对所有人都一样，已经内置在 [`settings.py`](custom_components/shenzhen_gas/settings.py) 里，不需要任何配置文件或环境变量。只有深圳燃气改域名/升小程序版本时才需要改那份常量。

以前版本需要的 `.env` / 环境变量已移除，装好即可用。

## CodeId 说明

深圳燃气部分业务接口会校验微信小程序请求头里的 `CodeId`。集成也会使用 `CodeId` 读取当前微信小程序账号已绑定的燃气账户列表。

`CodeId` 通常长期不变，只需要获取一次。更换微信号、重新绑定账户或深圳燃气后端调整时，可能需要重新获取。

请勿公开自己的 `CodeId`、客户号、燃气表号或抓包文件。

## 常见问题

### 连接失败

界面上现在会区分三种情况：

| 提示 | 含义 |
| --- | --- |
| `CodeId 无效` | 服务端没有这个 CodeId 对应的小程序账号（接口 40507），重新抓取 CodeId |
| `该 CodeId 被服务端拒绝访问` | 接口 40510，通常表示 CodeId 已失效，重新抓取即可 |
| `连接失败：无法访问深圳燃气接口` | 网络/DNS 不通，检查 HA 能否访问 `wechat.szgas.com.cn` |

其他细节（HTTP 状态码、服务端原始 `msg`）会写进 HA 日志，搜索 `shenzhen_gas` 即可。

### 部分实体为空

可能原因：

- 当前账户没有对应数据
- 账单尚未出账
- 深圳燃气接口临时异常
- 表具没有上报最新数据

### CodeId 会过期吗？

`CodeId` 不像接口 `access_token` 那样频繁过期。集成会自动刷新 `access_token`，但如果深圳燃气返回未登录、缺少参数或页面加载失败，可以尝试重新获取 `CodeId`。
